# Monitoring Concepts

## Definition

Monitoring collects and evaluates known signals so operators can detect unhealthy states and respond to expected failure conditions.

## Why It Matters

A monitoring system should make operational state visible without becoming the only source of system knowledge.

## Key Ideas

Metrics, logs, checks, alert thresholds, notification routing, and maintenance windows solve different operational problems.
