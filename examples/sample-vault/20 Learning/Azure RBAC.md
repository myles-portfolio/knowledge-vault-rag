# Azure RBAC

## Summary

Role-based access control determines what actions an identity can perform against resources within a defined scope.

## Key Concepts

A role assignment combines a security principal, a role definition, and a scope. Scope can be applied at progressively narrower levels such as a subscription, resource group, or individual resource.
